# FCC v8 Evaluation Model

Reviewer e evaluator são papéis distintos. O reviewer procura problemas; o evaluator verifica se o contrato foi cumprido.

## Resultado
`PASS | FAIL | PARTIAL`, score, critérios, evidências, regressões e confiança.

## Gates
1. Contract completo
2. Cobertura de evidência
3. Fresh review para risco alto
4. Evaluator pass
5. Approval gate quando necessário
