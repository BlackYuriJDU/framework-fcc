# FCC v8 Contracts

A unidade de trabalho do FCC v8 é o **Task Contract**. Agentes são executores especializados; contratos definem objetivo, domínio, modo, risco, escopo, sucesso, verificação e artefatos.

## Lifecycle
`INTAKE → CONTRACT → CONTEXT → PLAN → EXECUTE → VERIFY → EVALUATE → FINALIZE`

## Artifacts
Cada tarefa não trivial deve deixar `CONTRACT.yaml`, `STATE.yaml`, `EVIDENCE.md`, `RESULT.md` e `NEXT.md` em `tasks/YYYY/MM/<task-id>/`.

`docs/CROSS_TEAM.md` permanece compatível, mas cross-team passa a ser uma especialização de Task Contract.
