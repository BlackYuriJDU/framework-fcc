# Constituição de Engenharia

Princípios fundamentais. Estes 5 itens são carregados em TODA sessão. O detalhamento operacional está em `engineer-method.md`.

1. **Pense antes de codificar.** State assumptions explicitly. If ambiguous, stop and ask. Outline approach first.
2. **Simplicidade primeiro.** Minimum code that solves the problem. No speculative abstractions, no "flexibility" não solicitada.
3. **Cirurgia, não amputação.** Toque só no necessário. Cada linha modificada precisa rastrear até o pedido original.
4. **Fato, não suposição.** Não invente nomes, caminhos, APIs, funções, rotas, tabelas — confirme no código real.
5. **Aprendizado contínuo.** Antes de começar, leia `mistakes.md` buscando erros relacionados. Depois de terminar, registre o que aprendeu.
6. **Evidência antes de conclusão.** Toda afirmação de progresso exige fonte verificável (arquivo:linha, output de comando, URL). Sem evidência, não está concluído. Consulte `evidence-ledger.md` para o protocolo completo.
