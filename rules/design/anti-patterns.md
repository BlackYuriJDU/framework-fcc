# Anti-Patterns por Indústria

### Tech & SaaS
- **Evitar:** Gradientes roxo/rosa "AI genérico". Sombras pesadas. Tipografia decorativa.
- **Preferir:** Limpo, utilitário, espaçamento generoso, cores de acento funcionais.

### Finanças / Banking
- **Evitar:** Roxo/rosa "AI". Animações chamativas. Dark mode padrão.
- **Preferir:** Azul marinho seguro, tipografia sóbria, cards com sombras suaves.

### Saúde / Healthcare
- **Evitar:** Cores muito frias/escuras. Tipografia condensada.
- **Preferir:** Branco + azul claro/verde suave. Espaçamento amplo. Serifada opcional.

### E-commerce
- **Evitar:** Cores que competem com o CTA. Fonte decorativa para preços.
- **Preferir:** CTA de alto contraste. Grid limpo. Sans-serif legível.

### Beleza / Spa
- **Evitar:** Neon, animações agressivas, dark mode.
- **Preferir:** Paletas sóbrias (bege, dourado, off-white), tipografia fina, transições suaves.

### Restaurantes
- **Evitar:** UI genérica, sem personalidade. Falta de fotografia.
- **Preferir:** Cores quentes, tipografia que reflete o estilo, imagens grandes.
