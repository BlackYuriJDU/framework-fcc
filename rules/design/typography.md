# Tipografia

### Fontes do ecossistema
- **Display/Sans:** Space Grotesk — títulos e labels.
- **Body:** Manrope — legível, moderno, texto corrido.
- **Mono:** JetBrains Mono — código e dados técnicos.
- **Serif (opcional):** Cormorant ou Playfair Display — apenas para moda, editorial, healthcare premium.

### Regras
- Display: pesos médio a bold, tracking ajustado para títulos.
- Body: peso regular, line-height 1.5-1.6.
- Mono: peso regular, tamanho 13-14px para código.
- Hierarquia: Título > Subtítulo > Corpo > Label. Use peso + tamanho + cor, não só cor.
