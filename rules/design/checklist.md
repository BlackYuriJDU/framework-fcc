# Design Checklist

Obrigatório ao finalizar QUALQUER alteração de front-end.

- [ ] **SVG icons** — Nunca emoji como ícone. Heroicons ou Lucide (já no projeto).
- [ ] **cursor-pointer** — Em todo elemento clicável (botões, links, cards).
- [ ] **Hover transitions** — 150-300ms, smooth. Nada abrupto.
- [ ] **Contraste de texto** — Mínimo 4.5:1 light mode, texto normal.
- [ ] **Focus states** — Visíveis para teclado. Não remover `outline` sem substituto.
- [ ] **Reduced motion** — `prefers-reduced-motion`. Animações não essenciais desativadas.
- [ ] **Breakpoints** — Testar 375px, 768px, 1024px, 1440px.
