# Design System Rules

## Regras fundamentais
1. **Consistência > Inovação** — Interface previsível é mais usável que criativa.
2. **Hierarquia visual clara** — Peso + tamanho + cor, não apenas cor.
3. **Espaçamento 8px grid** — Múltiplos de 4 ou 8.
4. **Bordas:** 2px ênfase, 1px neutro. `border-radius` 2px (editorial) ou 4-6px (UI padrão).
5. **Sombras:** Sutis ou ausentes. Nada dramático.
6. **Dark mode:** Não é espelho do light. Reduzir saturação, aumentar contraste em superfícies.
7. **Touch targets:** Mínimo 44x44px em mobile.

## Estilos por Contexto
| Contexto | Estilo | Características |
|----------|--------|-----------------|
| Landing page | Editorial / Premium | Tipografia expressiva, imagens grandes, animações sutis |
| Dashboard | Clean / Data-dense | Grid, cards, tipografia compacta, foco em dados |
| SaaS / App | Functional / Minimal | Componentes padrão, UX previsível, performance |
| E-commerce | Conversion-Optimized | Hierarquia preço/CTA, provas sociais, trust signals |
| Mobile-first | Bento Box / Card-based | Cards modulares, gestos naturais, bottom nav |
