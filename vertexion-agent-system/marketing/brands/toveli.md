# Toveli — baseline de marca

- **Proposta:** aplicativo mobile-first para pequenos negócios e equipes organizarem clientes, rotina, cobranças e pagamentos.
- **Público:** empreendedores brasileiros, startups e pequenas equipes.
- **Tom:** prático, acolhedor, objetivo e sem burocracia.
- **Idiomas:** pt-BR.
- **Mensagem central:** controle diário do negócio no celular.
- **Evitar:** posicionar como ERP pesado, prometer banco definitivo durante MVP, expor que a persistência é provisória.
- **CTA:** organizar equipe, registrar cliente, acompanhar cobrança.
- **Inconsistências:** identidade visual e escopo devem ser confirmados no código mais atual.
