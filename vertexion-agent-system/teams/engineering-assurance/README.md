# Engineering Assurance

A configuração global contém os agentes atuais. Esta pasta preserva avaliações, contratos, aprendizado e relatórios do pipeline v3.

Diferenças principais:

- comandos antigos substituídos por Skills;
- deploy separado e manual;
- sem commit/stash/push automático;
- scope guardian obrigatório;
- segurança Supabase e pagamentos especializadas;
- documentação e compliance condicionais;
- memória só após confirmação e teste;
- Toveli possui plano de correção dedicado.
