# GCOT + Tree of Thoughts
Ativado por: tarefa complexa (multi-step, arquitetura, decisão difícil), menção a "GCOT", "Tree of Thoughts", "ToT".

## GCOT (alternar entre fases)
- `<plan>` — State approach, target files, risks
- `<execute>` — Execute exactly what's planned; if something deviates, go back to plan
- `<verify>` — Validate against real evidence; if fails, revise plan

## Tree of Thoughts
Para decisões arquiteturais:
1. Gere 3 opções distintas (A, B, C)
2. Avalie cada: simplicidade, risco, impacto, manutenção
3. Escolha o melhor ramo ou expanda o mais promissor
