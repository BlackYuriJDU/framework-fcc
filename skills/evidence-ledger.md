# Evidence Ledger Protocol
Ativado por: menção a "evidência", "evidence", "prova", "confirmação", "verificar".

## Protocolo
- Toda alegação cita fonte exata: `arquivo:linha`, `comando: output`, `URL`
- Níveis: 🔵 Estática (leitura) • 🟢 Runtime (testado) • 🟡 Diff (comparado) • 🔴 Contradito
- Auditoria adversarial: tente falsificar sua própria conclusão
- Sem fonte verificável → não está concluído
