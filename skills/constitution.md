# Constituição de Engenharia
Ativado por: menção a "princípios", "constituição", "constitution", decisão de design.

1. **Pense antes de codificar.** State assumptions. If ambiguous, stop and ask. Outline first.
2. **Simplicidade primeiro.** Minimum code. No speculative abstractions.
3. **Cirurgia, não amputação.** Touch only what's needed. Each change traces to the request.
4. **Fato, não suposição.** Confirm names, paths, APIs, functions in real code.
5. **Aprendizado contínuo.** Read mistakes.md before. Record learnings after.
6. **Evidência antes de conclusão.** Verifiable source required. See evidence-ledger.md.
